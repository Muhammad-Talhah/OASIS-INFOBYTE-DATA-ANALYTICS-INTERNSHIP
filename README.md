### **OASIS INFOBYTE DATA ANALYTICS INTERNSHIP**



###### **This repository contains all 9 projects I have completed during my Data Analytics Internship at Oasis Infobyte.**



#### **PROJECTS:**



##### **1. ANALYZING GOOGLE PLAY STORE DATA**

\- Description: Comprehensive analysis of Google Play Store apps including ratings, reviews, categories, and market trends

\- Technologies: Python, Pandas, Matplotlib, Seaborn

\- Key Features: Data cleaning, category analysis, sentiment analysis of user reviews, market trend visualization

\- Skills: Data preprocessing, visualization, statistical analysis, market insights



##### **2. AUTOCOMPLETE AND AUTOCORRECT DATA ANALYTICS**

\- Description: NLP-based text prediction and correction system using edit distance and n-grams

\- Technologies: Python, NLTK, N-grams, Edit Distance algorithms

\- Key Features: Autocomplete suggestions, autocorrect functionality, vocabulary building from structured data

\- Skills: Natural Language Processing, algorithms, text processing



##### **3. CUSTOMER SEGMENTATION ANALYSIS**

\- Description: Customer segmentation using K-Means clustering to identify different customer groups

\- Technologies: Python, Scikit-learn, K-Means Clustering, PCA, StandardScaler

\- Key Features: RFM analysis, customer profiling, market segmentation, cluster visualization

\- Skills: Machine Learning, clustering algorithms, customer analytics, visualization



##### **4. DATA CLEANING**

\- Description: Comprehensive data cleaning pipeline for messy datasets

\- Technologies: Python, Pandas, NumPy, Seaborn

\- Key Features: Missing value handling, outlier detection, duplicate removal, data standardization

\- Skills: Data preprocessing, quality assurance, data validation



##### **5. EXPLORATORY DATA ANALYSIS (EDA)**

\- Description: In-depth exploratory analysis of retail sales data

\- Technologies: Python, Pandas, Matplotlib, Seaborn

\- Key Features: Time series analysis, customer demographics, product performance, correlation analysis

\- Skills: Statistical analysis, data visualization, business insights generation



##### **6. FRAUD DETECTION**

\- Description: Machine learning system to detect fraudulent credit card transactions

\- Technologies: Python, Scikit-learn, SMOTE, Logistic Regression, Random Forest

\- Key Features: Class imbalance handling, real-time fraud detection, model comparison

\- Skills: Machine Learning, classification algorithms, anomaly detection, model evaluation



##### **7. HOUSE PRICES WITH LINEAR REGRESSION**

\- Description: House price prediction using Linear Regression model

\- Technologies: Python, Scikit-learn, Linear Regression, StandardScaler

\- Key Features: Feature engineering, model training, residual analysis, price prediction

\- Skills: Regression analysis, feature selection, model interpretation



##### **8. SENTIMENT ANALYSIS**

\- Description: NLP-based sentiment analysis of Twitter data using machine learning

\- Technologies: Python, NLTK, TF-IDF, Naive Bayes, Logistic Regression, SVM

\- Key Features: Text preprocessing, sentiment classification, model comparison, real-time prediction

\- Skills: Natural Language Processing, text classification, sentiment scoring



##### **9. WINE QUALITY PREDICTION**

\- Description: Wine quality classification based on chemical properties

\- Technologies: Python, Scikit-learn, Random Forest, SGD Classifier, SVC

\- Key Features: Binary classification, feature importance analysis, model comparison

\- Skills: Classification algorithms, feature importance, quality prediction
